## 💡 Why SqliteVector.NET?

As the demand for local vector databases explodes in the AI era, existing solutions (like `sqlite-vec`) often require C/C++ native extension plugins. This can lead to native dependency headaches (e.g., `DllNotFoundException`, OS-specific compilation) when deploying cross-platform in .NET.

**SqliteVector.NET** solves this perfectly. Using only pure `.NET` features and the standard `Microsoft.Data.Sqlite`, we implemented a blazing-fast vector search using **100% Managed C# code**.

### ✨ Key Features

- **Zero Native Dependencies**: No C/C++ compilers or external native binaries needed. If .NET runs, this runs.
- **Blazing Fast (SIMD Accelerated)**: Uses C# `System.Numerics.Tensors.TensorPrimitives` for hardware acceleration (AVX2/AVX-512) to search hundreds of thousands of vectors in milliseconds.
- **Zero-Allocation Search Loop**: Garbage Collector (GC) allocations are strictly `0 Bytes` inside the search loop to prevent memory spikes.
- **Metadata Support**: Store and retrieve original text (Payload/Metadata) alongside your vectors.
- **Any AI Model**: Pass your dimensions in the constructor to perfectly support any embedding model (e.g., OpenAI 1536, HuggingFace E5 384).

## 🚀 Quick Start

```csharp
using SqliteVector.Net;

// 1. Initialize: Set DB path and dimensions (e.g., OpenAI text-embedding-3-small is 1536)
using var store = new SqliteVectorStore("my_rag_db.sqlite", dimensions: 1536);

// 2. Upsert Data
// Prepare your float[] vector generated by your AI model
float[] myVector = GetEmbeddingFromAI("Apples are tasty and healthy.");

// You can store metadata (like original text or JSON) alongside the vector
await store.UpsertAsync(
    id: "doc-001", 
    vector: myVector, 
    metadata: "Apples are tasty and healthy."
);

// 3. Search Data
float[] queryVector = GetEmbeddingFromAI("Tell me about healthy fruits");

// Search Top 3 most similar vectors
var results = await store.SearchAsync(queryVector, topK: 3);

foreach (var result in results)
{
    Console.WriteLine($"ID: {result.Id}");
    Console.WriteLine($"Score: {result.Score}");
    Console.WriteLine($"Metadata: {result.Metadata}");
}
```

## 왜 SqliteVector.NET 인가요?

AI 시대를 맞아 로컬 벡터 데이터베이스의 수요가 폭발적으로 증가하고 있습니다. 하지만 기존 솔루션(`sqlite-vec` 등)은 C/C++ 네이티브 확장 플러그인을 요구하여 **Windows/Linux/Mac 크로스 플랫폼 배포 시 네이티브 의존성 문제(DllNotFoundException 등)**를 일으키곤 합니다.

**SqliteVector.NET**은 이 문제를 완벽히 해결합니다. 
순수 `.NET` 기능과 기본 `Microsoft.Data.Sqlite`만을 사용하여 **100% Managed C# 코드**로 빛의 속도에 가까운 벡터 검색을 구현했습니다.

### ✨ 주요 특징 (Features)

- **Zero Native Dependencies**: C/C++ 플러그인 컴파일러나 외부 바이너리가 전혀 필요 없습니다. `.NET`이 도는 곳이면 어디서든 동작합니다.
- **Blazing Fast (SIMD Accelerated)**: C# `System.Numerics.Tensors.TensorPrimitives`를 활용하여 AVX2/AVX-512 하드웨어 가속을 통해 수십만 개의 벡터를 밀리초 내에 검색합니다.
- **Zero-Allocation Search Loop**: 검색 루프 내에서 가비지 컬렉터(GC) 할당을 0으로 만들어 메모리 스파이크를 방지합니다.
- **Metadata Support**: 벡터뿐만 아니라 원본 텍스트(Payload/Metadata)를 함께 저장하고 즉시 꺼내 쓸 수 있습니다.
- **Any AI Model**: 생성자에서 차원(Dimensions)을 지정하여 OpenAI(1536), HuggingFace E5(384) 등 모든 임베딩 모델과 완벽하게 호환됩니다.
